# SurpriseCore 🚀

A fun, lightweight terminal visualizer and alert script built in Python for Termux and Linux.

### Installation & Usage
Run these commands in your terminal:

```bash
pkg update && pkg install python -y
git clone [https://github.com/Amka-Kernel/surprisecore.git](https://github.com/Amka-Kernel/surprisecore.git)
cd surprisecore
python surprisecore.py
